판파국 GitHub Pages 배포용 파일

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더 안의 index.html 파일을 저장소 루트에 업로드합니다.
3. 저장소 Settings > Pages로 이동합니다.
4. Build and deployment에서 Deploy from a branch를 선택합니다.
5. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
6. 잠시 후 표시되는 GitHub Pages 주소로 접속하면 판파국이 열립니다.

주의:
- 현재 판파국의 게시글/프로필/재화/퀘스트 기록은 브라우저 localStorage에 저장됩니다.
- 같은 GitHub Pages 주소를 계속 사용하면 업데이트 후에도 저장 기록을 이어가기 쉽습니다.
- 저장 기록 백업 기능도 함께 사용하는 것이 안전합니다.
